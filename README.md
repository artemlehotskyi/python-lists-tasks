# Python: Списки і кортежі — задачі

Розв'язки задач з розділу **4.17.3 "Задачі"** посібника
[Python: Покрокове знайомство](https://pythonguide.rozh2sch.org.ua/).

Рівень — beginner. Без list comprehensions там, де звичайний цикл читабельніший.

## Файли

| # | Файл | Тема |
|---|------|------|
| 1 | [task_1_languages.py](task_1_languages.py) | `sorted()`, `reverse()`, `sort()` на списку мов |
| 2 | [task_2_sum_numbers.py](task_2_sum_numbers.py) | Сума чисел з рядка через `split()` |
| 3 | [task_3_cities_and.py](task_3_cities_and.py) | Форматування `'a, b, c, d, e and f'` через зріз і `join()` |
| 4 | [task_4_reverse_digits.py](task_4_reverse_digits.py) | Розворот списку цифр і збирання назад у число |
| 5 | [task_5_all_list_functions.py](task_5_all_list_functions.py) | Усі функції/операції зі списками з розділу 4 |
| 6 | [task_6_code_structure.py](task_6_code_structure.py) | Візуалізація структури коду з кортежа ключових слів |

## Запуск

```bash
python3 task_1_languages.py
echo "2 -1 9 6" | python3 task_2_sum_numbers.py
python3 task_3_cities_and.py
echo "1 2 3 4 5" | python3 task_4_reverse_digits.py
python3 task_5_all_list_functions.py
python3 task_6_code_structure.py
```
